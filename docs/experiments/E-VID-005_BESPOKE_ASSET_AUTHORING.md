# E-VID-005 — Bespoke Asset Authoring + JavaScript Direction

**Status:** ACTIVE EXPERIMENT

## Question

Can we materially raise the visual ceiling by separating premium asset authoring from deterministic JavaScript filmmaking, while preserving continuity, editability and full-programmatic 3-minute assembly?

## Hypothesis

A handpicked/bespoke high-information asset, once isolated and normalized, will outperform a primitive redraw for anatomy, architecture and hero props. JavaScript will provide more value as director/compositor/animator than as the sole illustrator.

## Asset-authoring candidates

Per Item, compare where applicable:

1. direct rights-cleared historical artwork or fragment;
2. bespoke trace/redraw/vectorization from one or more references;
3. bespoke generated illustration constrained by the Item requirements;
4. procedural primitive art when it is genuinely the strongest aesthetic choice.

Do not preselect method 1–4 globally.

## First benchmark Items

- Ingolstadt exterior;
- creature body/head/eye/hair;
- Victor head/hand/recoil/costume;
- apparatus contact macro.

## Required tests

For each HERO Item:

- full-size isolated asset;
- actual shot crop;
- thumbnail/delivery-size readability;
- house-style normalization;
- continuity against adjacent shot;
- one short motion/deformation test if movement matters;
- provenance/rights record;
- rejected alternatives.

## Success criterion

The new asset must clearly beat the V5.3 primitive lookdev in the actual shot, without creating a collage/template look or destroying animation continuity.

## Failure criterion

If premium static assets cannot be animated coherently enough, redesign the style/shot rather than adding more filters.
